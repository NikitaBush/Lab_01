# Лабораторная работа 1. Калькулятор и конвертер

Консольная программа с двумя командами: `calc` считает выражение,
`convert` переводит единицы.

## Установка (один раз)

```
python -m pip install -e .
python -m pip install pytest ruff
```

## Примеры

```
python -m toolkit --help
python -m toolkit calc "2 + 3 * -4"
python -m toolkit convert 5 --from km --to m
python -m toolkit convert 100 --from c --to f
```

## Как работает калькулятор

1. `tokenize` — делит строку на числа и операторы: `"2+3"` → `["2", "+", "3"]`.
2. `validate` — проверяет порядок и превращает строки в числа, унарный минус
   присоединяет к числу.
3. `calculate` — сначала выполняет `*` и `/`, потом `+` и `-`.

`eval` не используется.

## Конвертер

Длина: mm, cm, m, km. Масса: g, kg. Температура: c, f, k.

## Ошибки

При ошибке программа пишет сообщение в stderr и завершается с кодом 2.

## Проверка

```
python -m pytest
ruff check .
```
